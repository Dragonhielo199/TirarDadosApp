# Compilar la aplicación

1. Abre esta carpeta como proyecto en Android Studio.
2. Espera a que Gradle termine la sincronización.
3. Si Android Studio pide instalar el SDK de Android 36, instálalo desde SDK Manager.
4. Comprueba que Android Studio usa un JDK 17 o superior para Gradle.
5. Ejecuta `Build > Make Project`.
6. Para generar el APK: `Build > Generate App Bundles or APKs > Generate APKs`.

El archivo `local.properties` no se incluye a propósito: Android Studio lo crea con la ruta del SDK de cada ordenador.
