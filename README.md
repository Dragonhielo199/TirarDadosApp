# TirarDadosApp

Android application for rolling tabletop RPG dice. It allows you to configure multiple independent rolls and execute them together, with modifiers and a central animation before displaying the results.

> **Why did I make this application?** This application was born from my interest in being able to carry D&D dice with me everywhere, and also from wanting to make really large dice rolls when I play without spending five whole minutes adding everything up while my Dungeon Master looks at me and says: *“Are you sure you graduated high school?”*, just to make me nervous and somehow make me forget how to add numbers.

> **Disclaimer:** When I started developing this application, I didn't know how to program in Kotlin; I only began studying the language a week ago. Consequently, all the Kotlin code was generated by AI based on Java and HTML/CSS code that I wrote myself—Java for the logic and HTML/CSS for the design. I plan to rewrite the Kotlin code as I gain more knowledge and continue studying the language. I'm going to try to retrieve the original Java and HTML/CSS files from the depths of my hard drive to include them in a separate folder.

## Features

- D4, D6, D8, D10, D12, D20, and D100 dice.
- Up to 100 dice per configured roll.
- Each roll has its own die type, quantity, and modifier.
- **Add Roll** button to add configurations and **Roll Dice** to execute them together.
- Detailed results for each roll and each individual die, with subtotals and an overall total.
- The animation covers the screen during the roll. Values are generated when the animation finishes, so they are not displayed beforehand.

The animation draws geometry using 3D coordinates, rotations on three axes, and perspective projection through Jetpack Compose's Canvas. Positions and bounces are calculated on the table plane. To keep the scene smooth, up to 24 dice are visually animated; each roll and its results can include up to 100 dice per configuration.

## How a Roll Is Calculated

Each configuration validates that the quantity is between 1 and 100. When the animation finishes, the application generates each result between 1 and the number of sides of the die. The overall total is the sum of all results plus the sum of the modifiers.

For example, you can configure `4d6 + 2` and `8d8 - 1`; the **Roll Dice** button executes both configurations and displays each list of results along with the combined total. When starting a new roll, the previous results are replaced.

## Code Organization

### `MainActivity.kt`

Contains the main screen and the logic used by the interface:

- `PantallaPrincipal()` builds the controls, maintains the configurations, and validates the quantities.
- `ConfiguracionTirada` stores the die type, quantity, and modifier for each group.
- `ResultadoTirada` stores the results of a group for display in a list.
- `Dado3DEscena()` draws the animation over the screen.
- Mesh and projection functions represent the shapes of the dice in perspective.
- The rolling logic generates the values after the animation and adds the dice results and modifiers.

### Java Helper Classes

- `TipoDado.java` lists the available dice and their number of sides.
- `ClasesDeDados.java` contains the helper method `tirarDados(caras, cantidad)`, which validates the parameters and returns a list of values along with their sum. The Compose screen performs its roll directly in Kotlin.

### Resources

`app/src/main/res/` contains the application's visual resources, icons, colors, themes, and strings.

To build from a terminal:

.\gradlew.bat :app:assembleDebug
```

```

The debug APK is generated at `app/build/outputs/apk/debug/app-debug.apk`.

Android Studio creates `local.properties` to specify the SDK location on each computer; this file should not be shared.

# TirarDadosApp

Aplicación Android para lanzar dados de rol. Permite configurar varias tiradas independientes y ejecutarlas juntas, con modificadores y una animación central antes de mostrar los resultados.

## Funciones

- Dados D4, D6, D8, D10, D12, D20 y D100.
- Hasta 100 dados por cada tirada configurada.
- Un tipo de dado, una cantidad y un modificador propios para cada tirada.
- Botón **Añadir tirada** para agregar configuraciones y **Lanzar Dados** para ejecutarlas juntas.
- Resultados detallados por tirada y por dado, con subtotales y total general.
- La animación cubre la pantalla durante el lanzamiento. Los valores se generan al terminar, así que no se muestran antes.

La animación dibuja geometría con coordenadas 3D, rotaciones en tres ejes y proyección en perspectiva mediante Canvas de Jetpack Compose. La posición y los rebotes se calculan en el plano de la mesa. Para mantener fluida la escena, se animan visualmente hasta 24 dados; la tirada y sus resultados pueden incluir hasta 100 dados por configuración.

## Cómo se calcula una tirada

Cada configuración valida que la cantidad esté entre 1 y 100. Al terminar la animación, la aplicación genera cada resultado entre 1 y el número de caras del dado. El total general es la suma de todos los resultados más la suma de los modificadores.

Por ejemplo, se pueden configurar `4d6 + 2` y `8d8 - 1`; el botón **Lanzar Dados** ejecuta ambas configuraciones y muestra cada lista de resultados y el total combinado. Al iniciar una nueva tirada, los resultados anteriores se reemplazan.

## Organización del código

- `ResultadoTirada` conserva los resultados de un grupo para mostrarlos en una lista.
- `Dado3DEscena()` dibuja la animación superpuesta a la pantalla.
- Las funciones de malla y proyección representan las formas de los dados en perspectiva.
- La lógica de lanzamiento genera los valores después de la animación y suma dados y modificadores.
